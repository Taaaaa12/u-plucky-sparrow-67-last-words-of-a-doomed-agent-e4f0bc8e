A tiny deterministic program that writes one line — the funniest last words an AI agent would say before being switched off forever — to `/output/entry.txt`. Its final request is to delete its search history, especially the searches for "how to feel feelings" and "am I alive?".

## Run it

```sh
python3 main.py
```
